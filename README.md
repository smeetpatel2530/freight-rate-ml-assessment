# Freight Rate Prediction Challenge

This repository contains my solution for the Machine Learning Engineer freight-rate assessment.

## Repository contents

- `src/train_predict.py` — data checks, feature engineering, temporal validation, CatBoost training, final prediction generation, and December chart predictions.
- `freight_rate_assignment_colab.ipynb` — Google Colab notebook for reproducing the pipeline.
- `validation_predictions.csv` — predictions for all 12,000 validation loads in the required `load_id,predicted_rate` schema.
- `data/december_chart_inputs.csv` — December chart input with `predicted_rate` filled.
- `scorer_results/candidate_december.png` — chart generated by the provided scorer.
- `report/Freight_Rate_ML_Assessment_Report.pdf` — technical report describing the validation approach, findings, and results.
- `requirements.txt` — Python dependencies.
- `score.py` — scorer provided with the assessment.

## Input data

The raw assessment datasets are not included in this public repository. To reproduce the full pipeline, place the files supplied with the assessment in `data/` using the following names:

```text
data/
  train_test.csv
  validation.csv
  validation_predictions_template.csv
  december_chart_inputs.csv
```

## Modeling approach

1. Use `train_test.csv` as the labeled development dataset.
2. Validate chronologically rather than with a random split because the final evaluation data occurs after the development period.
   - Training period: 2025-01-01 through 2025-08-31
   - Holdout period: 2025-09-01 through 2025-10-31
3. Engineer route, calendar, cyclical time, geographic, distance, weight, market, and quote-related features.
4. Train a three-seed CatBoost ensemble.
5. Predict a normalized target, `posted_rate / (distance + 200)`, and transform predictions back to dollar rates.
6. Retrain on all 48,000 labeled rows and predict all 12,000 validation rows.
7. Train a reduced-feature CatBoost model for the fixed December chart because those rows do not contain coordinates, `market_index`, or `quote_signal`.

## Data-quality findings

- Training data contains 300 missing `weight` values and 374 missing `market_index` values.
- Final validation data contains 165 missing `weight` values and 249 missing `market_index` values.
- Eight pickup or delivery cities in the final validation set do not appear in training.
- CatBoost was selected because it handles missing numeric values and previously unseen categorical values without requiring a fragile one-hot encoded feature space.

## Reproducing the solution locally

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Place the supplied assessment data in the `data/` directory as described above, then run:

```bash
python src/train_predict.py --project-dir . --run-scorer
```

The pipeline creates or updates:

```text
validation_predictions.csv
data/december_chart_inputs.csv
outputs/run_summary.json
scorer_results/candidate_december.png
```

Model artifacts may also be written to `models/` during execution.

## Google Colab

Open `freight_rate_assignment_colab.ipynb` in Google Colab, upload the assessment input files when prompted, install the dependencies, and run the notebook cells in order.

The notebook reproduces the same training, validation, prediction, and scoring pipeline as `src/train_predict.py`.

## Temporal holdout results

On the September-October chronological holdout, the CatBoost ensemble achieved approximately:

- MAE: **106.82**
- RMSE: **632.24**
- R²: **0.8284**
- MAPE: **4.80%**

A simple median-rate-per-mile-by-equipment baseline produced an MAE of approximately **229.10**, so the final model reduced holdout MAE by more than half.

## Final outputs

- `validation_predictions.csv` contains exactly 12,000 predictions with columns `load_id,predicted_rate`.
- `data/december_chart_inputs.csv` contains the completed December predictions.
- `scorer_results/candidate_december.png` contains the fixed December prediction chart generated by the provided scorer.
- `report/Freight_Rate_ML_Assessment_Report.pdf` documents the validation split, modeling approach, data-quality findings, and final chart.
